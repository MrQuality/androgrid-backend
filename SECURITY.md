# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported |
| :--- | :--- |
| Latest (`main`) | :white_check_mark: |
| Older releases | :x: |

---

## Reporting a Vulnerability

The AndroGrid team takes security vulnerabilities seriously.

If you believe you have discovered a vulnerability in this project:

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately through GitHub Security Advisory:
   - Navigate to the **Security** tab of this repository.
   - Click **Report a vulnerability**.
3. Alternatively, contact the maintainer directly via the contact methods listed on the repository profile.

### What to Include in Your Report
- A detailed description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or proof-of-concept (PoC) code.
- Suggested remediations or mitigations, if known.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide regular status updates regarding verification and patch deployment.
- We kindly ask for responsible coordinated disclosure while a fix is being prepared.
